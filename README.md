# کارخانه (Karkhaneh)

خانه‌ی کار تصویر

## درباره پروژه

کارخانه یک هاب تخصصی تصویر در شیراز است که چهار بخش اصلی دارد:

- کارخانه: فروش تجهیزات نو و دست دوم عکاسی، فیلمبرداری، صدا و نور همراه با خدمات پس از فروش.
- تعمیرخانه: مرکز تعمیر تجهیزات تصویر و صدا و نمایندگی سیرنگ سرویس در شیراز.
- تاریکخانه: خدمات آنالوگ شامل ظهور و اسکن فیلم، فروش فیلم و خرید و فروش دوربین‌های آنالوگ.
- کتابخانه: فروش کتاب‌های تخصصی عکاسی، سینما و هنر.

## هدف وب‌اپلیکیشن

ساخت یک پلتفرم دیجیتال برای معرفی، فروش، مدیریت خدمات و ایجاد ارتباط میان جامعه تصویر شیراز و کارخانه.

## مسیر توسعه

- فاز اول: معرفی برند و چهار بخش اصلی
- فاز دوم: فروشگاه، تعمیرات و خدمات
- فاز سوم: پنل مدیریت و عملیات داخلی
